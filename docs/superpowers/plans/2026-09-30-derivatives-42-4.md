# Phase 42.4: continuous futures data — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A strategy can declare `btc = BINANCE_UM:BTCUSDT@front EVERY 15m` and backtest it on real
per-contract data: the stream is stitched point-in-time from the contract chain, forward-adjusted,
with rolls at the policy instants and roll gaps taken from a persisted roll history.

**Architecture:** The DSL keeps the selector inside the stream symbol (`BTCUSDT@front`), so no AST
shape changes. A per-root **roll history** (`contracts/<VENUE>/<ROOT>.rolls.json`) holds the two
contracts' reference prices at every roll, built once by `qkt fetch <ROOT> --rolls`; live will append
to the same file. A pure **`ContinuousChain`** turns catalog + policy + history into "which contract,
at what shift" for any instant. A **`ContinuousMarketSource`** decorates the store source and serves
stitched bars/ticks for continuous symbols (and cuts explicit contracts at expiry). The instrument
registry exposes the chains through a new default method, so the replay engine and the market source
reach them without new parameters through baselined files. Order execution still fills in continuous
space in this phase (PaperBroker on the continuous symbol); contract-level execution and rolls of
positions are phase 42.5.

**Spec:** `docs/superpowers/specs/2026-09-30-futures-options-design.md` (§5.2–5.4, §5.11, §11 E3–E5, E16, E17)

## Global constraints

- CFD golden pins and the DSL corpus pin stay green; no field added to `StreamDecl`/`HubKey`/AST.
- Files ≤ 200 lines (tests ≤ 220); baselined files only shrink (extract first, `updateFileSizeBaseline`).
- Money `BigDecimal`; KDoc on public API; commits via the helper (subject ≤ 70 chars).
- Bars stamped at or after a contract's expiry are never served.

## Review focus

- A stream timeframe whose bars would span a roll instant (e.g. `1d` bars with an 08:00 roll) → refused before the run with a message naming the timeframe and roll time (Task 6 test).
- A backtest window that needs a roll the history does not contain → refused with the command that builds it (Task 3 test).
- `@next` near the end of the chain → the stream ends cleanly when its contract runs out, no exception mid-run (Task 6 test).
- A roll history built under one policy read under another (days/time changed in `instruments.yaml`) → refused, never silently mixed (Task 2 test).
- An existing CFD strategy parsed after the parser change → identical AST (corpus pin) and identical backtest (golden pins).

```kotlin
package com.qkt.instrument

import java.math.BigDecimal
import kotlinx.serialization.Serializable

/**
 * The two contracts' reference prices at one roll instant: [fromPrice] of the contract being left,
 * [toPrice] of the contract being entered, as exact decimal strings.
 */
@Serializable
data class RollRecord(
    val atMs: Long,
    val from: String,
    val to: String,
    val fromPrice: String,
    val toPrice: String,
) {
    init {
        require(fromPrice.toBigDecimalOrNull()?.signum() == 1) { "RollRecord.fromPrice must be > 0: $fromPrice" }
        require(toPrice.toBigDecimalOrNull()?.signum() == 1) { "RollRecord.toPrice must be > 0: $toPrice" }
    }

    /** [fromPrice] as a number. */
    fun fromPriceValue(): BigDecimal = BigDecimal(fromPrice)

    /** [toPrice] as a number. */
    fun toPriceValue(): BigDecimal = BigDecimal(toPrice)
}

/**
 * Every measured roll of one root under one policy ([policy] is [RollPolicy.key]). Built once from
 * stored bars by `qkt fetch <ROOT> --rolls`; a live session appends the gaps it measures, so a later
 * backtest of the same window reuses them exactly.
 */
@Serializable
data class RollHistory(
    val root: String,
    val policy: String,
    val rolls: List<RollRecord>,
) {
    /** The record for the roll at [atMs] from contract [from] to [to], or null. */
    fun find(
        atMs: Long,
        from: String,
        to: String,
    ): RollRecord? = rolls.firstOrNull { it.atMs == atMs && it.from == from && it.to == to }
}
```

- Produces: `class ContinuousChain(root: FuturesRoot, catalog: ContractCatalog, history: RollHistory?, selector: ContinuousSelector)` with

  - `fun indexAt(tMs: Long): Int?` — contract index followed at `tMs`
  - `fun contractSymbolAt(tMs: Long): String?` — `VENUE:CODE`

Rules:
- The selector with offset `o` follows contract `f + o` where `f` is the front index; its roll at
  transition `k` goes from contract `k + o` to `k + o + 1` at `transitions[k].atMs`.
- The history must match `root.roll.key` (else fail: "roll history was built for policy X; rebuild it
  with qkt fetch ROOT --rolls").
- Anchor = the contract index of the first history record that applies to this selector; contract
  `anchorIndex` has shift identity. A contract before the anchor, or a transition after the last
  record, fails with the command that builds more history.
- `root.roll == null` fails: continuous streams need a roll policy.

```kotlin
package com.qkt.derivatives.futures

import com.qkt.instrument.ContinuousSelector
import com.qkt.instrument.ContractCatalog
import com.qkt.instrument.FuturesRoot
import com.qkt.instrument.RollHistory

/** One stretch of a continuous stream served by contract [index], over `[fromMs, toMs)`. */
data class ChainSegment(
    val index: Int,
    val fromMs: Long,
    val toMs: Long,
)

/**
 * A continuous futures stream: which contract of [root] the [selector] follows at any instant, and
 * the forward adjustment that joins them, taken from the measured [history]. Pure and immutable;
 * the same catalog, policy and history give the same answers in backtest and live.
 */
class ContinuousChain(
    private val root: FuturesRoot,
    catalog: ContractCatalog,
    history: RollHistory?,
    private val selector: ContinuousSelector,
) {
    private val policy = requireNotNull(root.roll) { "futures root ${root.root} has no roll policy; a continuous stream needs one" }

    /** The continuous symbol, e.g. `BINANCE_UM:BTCUSDT@front`. */
    val symbol: String = selector.symbolFor(root.root)

    /** When each contract is front. */
    val schedule: RollSchedule = RollSchedule(catalog.contracts, policy)

    /** The first contract this stream's adjustment is anchored at. */
    val anchorIndex: Int

    private val adjustment: AdjustmentChain

    init {
        val measured = requireNotNull(history) { "no roll history for ${root.root}; build it with ${buildHint()}" }
        require(measured.policy == policy.key) {
            "roll history for ${root.root} was built for policy ${measured.policy}, but the root now rolls ${policy.key}; " +
                "rebuild it with ${buildHint()}"
        }
        val o = selector.offset
        val pairs =
            schedule.transitions.mapNotNull { t ->
                val from = schedule.contracts.getOrNull(t.fromIndex + o) ?: return@mapNotNull null
                val to = schedule.contracts.getOrNull(t.toIndex + o) ?: return@mapNotNull null
                measured.find(t.atMs, from.symbol, to.symbol)?.let { t.fromIndex to RollPrices(it.fromPriceValue(), it.toPriceValue()) }
            }
        require(pairs.isNotEmpty()) { "roll history for ${root.root} has no roll for $symbol; rebuild it with ${buildHint()}" }
        val first = pairs.first().first
        pairs.forEachIndexed { i, (k, _) ->
            require(k == first + i) { "roll history for ${root.root} misses the roll at ${schedule.transitions[first + i].atMs}; rebuild it with ${buildHint()}" }
        }
        anchorIndex = first + o
        adjustment = AdjustmentChain(policy.adjust, pairs.map { it.second })
    }

    /** Contract index followed at [tMs], or null when this stream has no contract then. */
    fun indexAt(tMs: Long): Int? = schedule.indexAt(tMs, selector)

    /** `VENUE:CODE` of the contract followed at [tMs], or null. */
    fun contractSymbolAt(tMs: Long): String? = indexAt(tMs)?.let(::contractSymbol)

    /** `VENUE:CODE` of contract [index]. */
    fun contractSymbol(index: Int): String = "${root.venue}:${schedule.contracts[index].symbol}"

    /** The price mapping of contract [index]; fails outside the measured history. */
    fun spaceFor(index: Int): PriceSpace {
        val position = index - anchorIndex
        require(position >= 0) {
            "$symbol needs ${contractSymbol(index)}, before the roll history starts; build more with ${buildHint()}"
        }
        require(position < adjustment.size) {
            "$symbol needs ${contractSymbol(index)}, after the last measured roll; build more with ${buildHint()}"
        }
        return PriceSpace(policy.adjust, adjustment.shiftFor(position), root.tickSize)
    }

    /** The contiguous contract stretches covering `[fromMs, toMs)`, clipped to the chain's life. */
    fun segments(
        fromMs: Long,
        toMs: Long,
    ): List<ChainSegment> {
        val cuts = listOf(fromMs) + schedule.transitions.map { it.atMs }.filter { it in (fromMs + 1) until toMs } + toMs
        return cuts.zipWithNext().mapNotNull { (a, b) -> indexAt(a)?.let { ChainSegment(it, a, minOf(b, schedule.contracts[it].expiryMs)) } }
            .filter { it.fromMs < it.toMs }
    }

    private fun buildHint(): String = "qkt fetch ${root.root} --rolls"
}
```

**Interfaces:**

- Produces:
  - `class RollHistoryBuilder(bars: (contract: String, day: LocalDate) -> List<Candle>)` with `fun build(root: FuturesRoot, catalog: ContractCatalog, selectors: Set<ContinuousSelector> = all): RollHistory`
  - reference price of a contract at `atMs` = close of the last bar with `endTime ≤ atMs` from that UTC day, falling back to the previous day when `atMs` is at 00:00

The bar timeframe used for reference prices is `1m` (the finest Binance kline and the store's
default for fetched futures). `fetchDay(contract, day)` downloads one day of 1m bars for
`VENUE:contract` into the store if it is not there; the CLI wires it to the venue's `BarFetcher` and
`LocalBarStore` exactly as `FetchCommand` does for one day.

```kotlin
package com.qkt.derivatives.futures

import com.qkt.instrument.ContinuousSelector
import com.qkt.instrument.ContractCatalog
import com.qkt.instrument.FuturesRoot
import com.qkt.instrument.RollHistory
import com.qkt.instrument.RollRecord
import com.qkt.marketdata.Candle
import java.math.BigDecimal
import java.time.Instant
import java.time.LocalDate
import java.time.ZoneOffset

/**
 * Measures a root's rolls from stored bars: at each roll instant, the last close at or before it for
 * the contract being left and the contract being entered. Stops at the first roll it cannot price,
 * so a history is always contiguous from its first roll.
 */
class RollHistoryBuilder(
    private val bars: (contract: String, day: LocalDate) -> List<Candle>,
) {
    /** The history of [root] over [catalog] for [selectors]. */
    fun build(
        root: FuturesRoot,
        catalog: ContractCatalog,
        selectors: Set<ContinuousSelector> = ContinuousSelector.entries.toSet(),
    ): RollHistory {
        val policy = requireNotNull(root.roll) { "futures root ${root.root} has no roll policy" }
        val schedule = RollSchedule(catalog.contracts, policy)
        val records = mutableListOf<RollRecord>()
        for (selector in selectors.sortedBy { it.offset }) {
            for (t in schedule.transitions) {
                val from = schedule.contracts.getOrNull(t.fromIndex + selector.offset) ?: break
                val to = schedule.contracts.getOrNull(t.toIndex + selector.offset) ?: break
                val fromPrice = priceAt(from.symbol, t.atMs) ?: break
                val toPrice = priceAt(to.symbol, t.atMs) ?: break
                records += RollRecord(t.atMs, from.symbol, to.symbol, fromPrice.toPlainString(), toPrice.toPlainString())
            }
        }
        return RollHistory(root.root, policy.key, records.distinct().sortedWith(compareBy({ it.atMs }, { it.from })))
    }

    private fun priceAt(
        contract: String,
        atMs: Long,
    ): BigDecimal? {
        val day = Instant.ofEpochMilli(atMs).atZone(ZoneOffset.UTC).toLocalDate()
        return (bars(contract, day) + bars(contract, day.minusDays(1)))
            .filter { it.endTime <= atMs }
            .maxByOrNull { it.startTime }
            ?.close
    }
}
```

Note the history "stops at the first unpriced roll" per selector: a `NEXT` break does not truncate
`FRONT` records already measured.

- Produces:
  - `class ContinuousChains(directory: FuturesDirectory)` with `fun chainFor(continuousSymbol: String): ContinuousChain?` (cached per symbol)
  - `class ContinuousMarketSource(inner: MarketSource, chains: ContinuousChains, instruments: InstrumentRegistry) : MarketSource` — same `name`/`capabilities` as `inner`; `supports` true for continuous symbols of declared roots and delegates otherwise
    - `bars(symbol, window, range)`: for a continuous symbol, for each `ChainSegment` in `range`, `inner.bars(contractSymbol, window, segmentRange)` mapped through `chain.spaceFor(index)` (open/high/low/close; bid/ask when present), re-stamped with the continuous symbol; for an explicit contract with `FutureTerms.expiryMs`, `inner.bars` filtered to `startTime < expiryMs`; anything else delegated unchanged
    - `ticks(symbol, range)` and `tickSlice(...)`: the same, per tick (price, bid, ask)
    - `liveTicks` delegated unchanged (live stitching is phase 44)
    - before serving bars of a continuous symbol, every roll instant in `range` must be a multiple of `window.durationMs` since the epoch; otherwise fail: `"$symbol rolls at <ISO>, inside a <tf> bar; use a timeframe that divides the roll time or move roll.atUtc"`

Mapping a candle: `high` and `low` map monotonically for panama and ratio (positive factor), so the
mapped high stays ≥ mapped low. A contract with no bars in a segment contributes nothing (E3); the
stream simply resumes at the next segment with data.
