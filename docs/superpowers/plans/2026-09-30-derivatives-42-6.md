# Phase 42.6: futures in the DSL and the reports — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A futures backtest reads like a CFD one and says what it did: strategies can see the
contract behind a stream (`contract`, `dte`, `days_to_roll`, `tick_value`, `multiplier`); reports
gain `rolls.csv`, `contracts.csv` and `settlements.csv` for futures runs only; the cost bridge and
the execution note are true for futures; orders that open exposure on a contract close to expiry are
refused. The 42.5 review's deferred minors are closed.

**Architecture:** Two run ledgers join `RollLedger` in `ReplayBooks`: a `ContractFillLog` (every
engine fill on a continuous stream with the contract and contract price it executed at, written by
`StreamLane`, the translation boundary) and a `SettlementLog` (written by `ExpirySettlement`).
`BacktestResult` carries all three; the report writer, `ResultJson.renderArtifacts` and
`ReportManifest` emit each file only when its list is non-empty, so CFD reports stay byte-identical.
DSL fields are computed from `InstrumentRegistry.futures()` and the evaluation time, `Undefined`
on non-futures streams.

**Spec:** `docs/superpowers/specs/2026-09-30-futures-options-design.md` (§5.6 entry guard, §5.11, §5.12, §11 E12)

## Global constraints

- CFD golden pins and the DSL corpus pin stay green; trades.csv unchanged; no AST shape change.
- Files ≤ 200 lines (tests ≤ 220); baselined files only shrink.
- Money `BigDecimal`; KDoc on public API; commits via the helper (subject ≤ 70 chars).
- Every new field and artifact is documented in `docs/reference` in the same task.

## Review focus

- A CFD run's report directory is byte-identical (golden pins compare JSON and trades; the bundle test pins the manifest list).
- `btc.contract` / `btc.dte` on a CFD stream → `Undefined`, the rule does not fire, no exception.
- `days_to_roll` on `@next` uses the `@next` schedule; `dte` of an explicit contract counts to its own expiry.
- A strategy that scales in, partially exits and holds across rolls, long and short, ends with engine P&L equal to its contract legs (Task 4).
- The expiry guard refuses opens and adds but never an exit (Task 6).

### Task 1: 42.5 follow-ups
- `NonExecutionAccounting.publish` takes the symbol; `COST` events carry the stream (`CostIncurredBookingTest` asserts `symbol`).
- `StreamLane` caches one `PriceSpace` per contract index (no per-tick allocation); behaviour pinned by the existing suite.
- Commit `fix(app): attribute venue costs to their symbol` and `perf(broker): reuse contract price spaces per tick`.

### Task 2: contract fill and settlement logs
- `ContractFillLog` / `ContractFill(atMs, strategyId, stream, orderId, contract, side, quantity, contractPrice, streamPrice)` in `broker/continuous`; `StreamLane.onFilled` records every engine fill it republishes (settlement and roll-failure closes included).
- `SettlementLog` / `Settlement(atMs, strategyId, contract, side, quantity, price, deliveryPriceKnown)` in `broker/exchange`; `ExpirySettlement` records each settlement.
- `ReplayBooks` owns both; `BacktestResult.contractFills` and `.settlements` (default empty).
- Tests: lane records a fill with contract price; settlement records known/unknown delivery price.

### Task 3: futures report artifacts and the cost bridge
- `rolls.csv`: `time,stream,strategy,from,to,quantity,fromReference,toReference,gap,fromFill,toFill,fees,rollCost`.
- `contracts.csv`: `time,strategy,stream,orderId,contract,side,quantity,contractPrice,streamPrice`.
- `settlements.csv`: `time,strategy,contract,side,quantity,price,deliveryPriceKnown`.
- Emitted by `BacktestReportWriter`, listed by `ResultJson.renderArtifacts` and `ReportManifest` only when non-empty.
- `PerformanceReport.rollCostsPaid` (global and per strategy); JSON/text/HTML print it only when non-zero; the bridge KDoc becomes `preCostPnL = totalPnL + commissionPaid + swapPaid + rollCostsPaid`.
- Tests: futures report has the three files and manifest entries; the CFD bundle test's manifest list is unchanged.

### Task 4: the general identity on real data
- For any strategy that ends flat: engine realized = Σ contract sells − Σ contract buys over `contractFills` and roll legs − all fees. Pins on `btcusdt-rolls` / `btcusdt-3rolls`: a short across a roll, a scale-in at two prices, a partial exit between rolls.

### Task 5: DSL futures fields
- `candleFields` gain `contract` (`Value.Str`, the contract code without venue), `dte` (days to the active contract's expiry, decimal, from evaluation time), `days_to_roll` (days to the stream's next roll; explicit contracts: to expiry), `tick_value` (`tick_size × contract_size`); `metaFields` gains `multiplier` (alias of `contract_size`). All `Undefined` on non-futures streams.
- `contract`, `dte`, `days_to_roll` are not numeric candle fields for indicators except `dte`/`days_to_roll`; `contract` excluded from `numericCandleFields`.
- Regenerate `editor/textmate/qkt.tmLanguage.json`, `editor/vscode/...`, `editor/nvim/syntax/qkt.vim`; update `docs/reference/dsl/expressions.md`, `dsl-grammar.md`.
- Tests: values on continuous and explicit streams at fixed times; `Undefined` on a CFD stream; drift tests green.

### Task 6: expiry entry guard
- Root key `expiryGuardHours` (default 24). Orders on a dated contract that open or increase exposure within the window before expiry are rejected with a reason naming the expiry; exits pass. Implemented where the venue position is known: `ExchangeSimulator` (listed contracts). Continuous streams roll before the window (`daysBeforeExpiry` ≥ 1 is validated against it: a root whose roll falls inside its guard window is refused at load).
- Declared in the parity catalog (a live venue does not enforce it; phase 44 applies the same check in the contract venue wrapper).

### Task 7: futures execution note and evidence
- `BacktestCommand` prints the paper "fills at mid" note only when the run has non-futures symbols; runs with futures print one line naming the exchange simulator (executable price, slippage model, fees on every fill). `TextReportPrinter` execution line likewise. CFD output unchanged.
