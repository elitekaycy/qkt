# `.qkt` TextMate Grammar

Syntax highlighting for `.qkt` strategy files in TextMate-compatible editors. The file is generated; see
[Source of truth](#source-of-truth).

## Scopes

| Scope | Highlights |
|---|---|
| `comment.line.double-dash.qkt` / `comment.line.number-sign.qkt` / `comment.block.qkt` | `-- foo`, `# foo`, `/* foo */` |
| `string.quoted.double.qkt` / `string.quoted.single.qkt` | `"foo"`, `'foo'` — single-line, like the lexer |
| `constant.character.escape.qkt` / `invalid.illegal.escape.qkt` | `\\` `\'` `\"` `\n` `\t` are escapes; any other `\x` is an error |
| `constant.numeric.qkt` / `constant.numeric.duration.qkt` | `1.5`, `30m` (`s`, `m`, `h`, `d`) |
| `constant.language.boolean.qkt` / `constant.language.qkt` | `TRUE`, `FALSE` / `ONE_PERCENT`, `BPS`, ... |
| `keyword.control.section.qkt` | `STRATEGY`, `SYMBOLS`, `LET`, `RULES`, `SEQUENCE`, `PORTFOLIO`, ... |
| `keyword.control.flow.qkt` | `WHEN`, `THEN`, `FOR`, `EACH`, `DO`, `CASE`, `EVERY`, ... |
| `keyword.other.action.qkt` | `BUY`, `SELL`, `CLOSE`, `FLATTEN`, `LOG`, ... |
| `keyword.other.order.qkt` | `MARKET`, `LIMIT`, `STOP`, `TRAILING`, `TIF`, `GTC`, ... |
| `keyword.other.sizing.qkt` | `SIZING`, `PCT`-less sizing words: `RISK`, `USD`, `OF`, `EQUITY`, ... |
| `keyword.other.bracket.qkt` | `BRACKET`, `OCO`, `TAKE`, `PROFIT`, `LATCH`, `ARM`, `RETRACE`, ... |
| `keyword.other.stacking.qkt` | `STACK`, `STAGE`, `SPACING`, `WITHIN`, `MFE`, `MAE`, ... |
| `keyword.other.portfolio.qkt` | `AS`, `RUN`, `HOLD`, `CAPITAL`, `WEIGHT`, `ALLOCATE`, ... |
| `keyword.other.session.qkt` | `HOUR`, `WEEKDAY`, `UTC`, `NY`, `LONDON`, `WARMUP`, `BARS`, ... |
| `keyword.other.hook.qkt` | `ON_FILL`, `ON_STOP`, `ON_TP`, `ON_CLOSE` |
| `variable.language.qkt` | `POSITION`, `NOW`, `ACCOUNT`, `EXIT`, `STREAK`, `TRADES`, `COOLDOWN`, ... |
| `keyword.operator.word.qkt` | `AND`, `OR`, `NOT`, `IS`, `NULL`, `BETWEEN`, `CROSSES`, `ABOVE`, `BELOW` |
| `support.function.aggregate.qkt` | `OPEN`, `MAX`, `MIN`, `MEAN`, `SUM` |
| `support.function.indicator.qkt` | `ema(`, `atr(`, `zscore(`, `resid(`, ... (every registered indicator) |
| `support.function.builtin.qkt` | `abs(`, `sqrt(`, `pow(`, `avg(`, `count(`, `calendar_window(`, ... |
| `support.variable.field.qkt` | `.close`, `.bid`, `.tick_size`, `.qty`, `.hour_utc`, ... after a dot |
| `variable.other.member.qkt` | any other identifier after a dot (`POSITION.gold`, `SEQUENCE.setup`) |
| `variable.other.alias.qkt` | `gold` in `gold = EXNESS:XAUUSD`, before a dot, or after `BUY`/`SELL`/`CLOSE`/`RESIZE` |
| `entity.name.namespace.qkt` | broker prefix in `EXNESS:XAUUSD` |
| `keyword.operator.qkt` | `=`, `==`, `<>`, `!=`, `<=`, `>=`, `<`, `>`, `->`, `+`, `-`, `*`, `/`, `%` |

Keywords match case-insensitively, as the lexer does. A word that is both a keyword and a function (`LOG`,
`FLOOR`, `MAX`, `MIN`) keeps its keyword scope even when called; indicator and function rules only fire before
a `(`, so an alias named `atr` stays an alias.

## Installing in VSCode

Use the extension under [`editor/vscode/`](../vscode/README.md), or create a minimal local extension:

```bash
mkdir -p ~/.vscode/extensions/qkt-syntax-local
cd ~/.vscode/extensions/qkt-syntax-local
ln -s /path/to/qkt/editor/textmate/qkt.tmLanguage.json qkt.tmLanguage.json
```

Create `~/.vscode/extensions/qkt-syntax-local/package.json`:

```json
{
  "name": "qkt-syntax-local",
  "publisher": "local",
  "version": "0.0.0",
  "engines": { "vscode": "^1.50.0" },
  "contributes": {
    "languages": [
      { "id": "qkt", "extensions": [".qkt"], "aliases": ["qkt"] }
    ],
    "grammars": [
      {
        "language": "qkt",
        "scopeName": "source.qkt",
        "path": "./qkt.tmLanguage.json"
      }
    ]
  }
}
```

Reload VSCode. Open any `.qkt` file. Use **Developer: Inspect Editor Tokens and Scopes** to verify scopes resolve.

## Installing in IntelliJ

Settings → Editor → TextMate Bundles → `+` → point to the `editor/textmate/` directory.

## Source of truth

`qkt.tmLanguage.json` is generated by `qkt editor grammar --format textmate` from
`src/main/kotlin/com/qkt/editor/TextMateGrammar.kt`: keywords from the lexer's `TokenKind`s grouped by
`KeywordCategory`, indicators and functions from `IndicatorRegistry` and `FuncRegistry`, constants from
`Constants`, fields from the compiler tables. Do not edit the JSON; change the generator or the language and
regenerate (see [editor/README.md](../README.md)). `GrammarFilesTest` fails on any drift.
